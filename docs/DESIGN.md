## 1. IA (정보 구조)

```
홈 /                          카테고리(6종) × 국내/해외 세그먼트 → 4개 랭킹 보드
 ├── 지금 뜨는 영상            α 0.25 · 업로드 7일 이내 (FR-2)
 ├── 신규 뜨는 영상            α 1.0 · 구독자 대비 배율 병기 (FR-3)
 ├── 지금 뜨는 유튜버          주간 성장률 (FR-4)
 └── 신규 뜨는 유튜버          구독 10만 이하 (FR-5, D7)
채널 상세 /channel/[id]        30일 구독자·일일 조회수 그래프 + 최근 급상승 영상 (FR-8, D6)
소개·정책 /about               자체 지표 설명(NFR-2) · 개인정보처리방침 · opt-out 안내(D12) · YouTube 출처 표기(NFR-1)
```

- 영상 행 클릭 → 유튜브 새 탭 (NFR-1, 재생은 유튜브에서). 채널명/아바타 클릭 → 채널 상세.
- admin 콘솔(FR-9)은 웹 화면이 아니라 리포에 커밋되는 마크다운 리포트 — DESIGN 범위 밖.

## 2. 레이아웃 (와이어프레임 요약)

- **홈 데스크톱**: 상단 내비(워드마크 + "자체 산출 지표" 뱃지 + 정책 링크 + 테마 토글) → 카테고리 칩 행(우측에 전체/국내/해외 세그먼트) → 산출 기준 시각 안내줄 → **보드 2×2 그리드**.
- **홈 모바일(≤760px)**: 보드 세로 1열, 카테고리 칩 가로 스크롤.
- **보드 행**: 순위 숫자(1·2위 강조) + 썸네일(영상)/아바타(채널) + 제목·메타 + 점수 pill.
- **채널 상세**: 헤더(아바타·채널명·카테고리 태그·구독자) → 미니 차트 2개(구독자/일일 조회수 — 스케일이 달라 이중축 대신 분리, 각 단일 시리즈) → 최근 급상승 영상 리스트.
- 차트 규격: 2px 라인 + 옅은 영역 채움 + 끝점 강조 + 희미한 그리드, 수치는 tabular-nums. 실구현 시 hover 크로스헤어+툴팁 포함.

## 5. 합의 기록

**2026-08-08 — 시안 v0.1 합의 완료 (v1.0).**
사용자가 시안을 확인한 뒤 "기본적으로 추천으로 진행" 지시에 따라 DQ1~DQ5를 위 표대로 확정했고,
M4 구현 착수를 승인했다. 시안 원본: [docs/design/mockup-v01.html](design/mockup-v01.html).

**구현 시 추가된 규격 (시안에 없던 상태들):**
- **콜드스타트 빈 상태** — 스냅샷이 2회 이상 쌓여야 점수가 나오므로, 오픈 전·수집 공백 시 보드가 빈다.
  "아직 집계 중" 안내를 보드 안에 두고 레이아웃은 유지한다 (보드가 사라지면 화면이 무너진다).
- **DB 조회 실패** — 해당 보드만 '조회 불가'로 표시하고 나머지는 렌더링한다 (NFR-9와 같은 원칙).
