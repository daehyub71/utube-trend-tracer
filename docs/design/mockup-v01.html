utube-trend-tracer — UI 디자인 시안

카테고리별 유튜브 트렌드 발견 서비스의 첫 시안입니다. 아래 목업의 데이터는 모두 가상의 예시이며, 합의 후 이 시안이 docs/DESIGN.md의 구현 기준이 됩니다.

검토용 시안 — 이 페이지는 시스템 테마에 따라 라이트/다크 시안이 함께 확인됩니다

1. 컬러 · 타이포

유튜브 레드는 의도적으로 쓰지 않습니다(출처 표기로만 사용, NFR-1). 브랜드 색은 "신호를 추적하는 트레이서"의 딥 틸, 급상승 수치에만 쓰는 엠버(heat)를 분리해 점수가 한눈에 도드라지게 합니다. 서체는 Pretendard(시스템 고딕 폴백), 수치는 tabular-nums.

Accent · 틸#0E7C86 / 다크 #45C2CC
Heat · 급상승#C2410C / 다크 #FF9163
Ink#17272A / 다크 #E6EEEE
Ground#F4F7F7 / 다크 #0E1719
Accent tint뱃지·선택 상태

2. 정보 구조 (IA)

화면은 3개로 유지합니다. 모든 영상·채널 클릭은 유튜브로 이동(NFR-1), 상세 페이지는 채널만 둡니다(D6).

홈 / ─ 카테고리(6) × 국내/해외 선택 → 4개 랭킹 보드
   ├── 지금 뜨는 영상        (α 0.25 · 업로드 7일 이내)
   ├── 신규 뜨는 영상        (α 1.0 · 구독자 대비 배율 표시)
   ├── 지금 뜨는 유튜버      (주간 성장률)
   └── 신규 뜨는 유튜버      (구독 10만 이하)
채널 상세 /channel/[id] ─ 30일 구독자·일일 조회수 그래프 + 최근 급상승 영상
소개·정책 /about ─ 자체 지표 설명 · 개인정보처리방침 · 채널 제외(opt-out) 안내

3. 홈 — 데스크톱

한 화면에서 "이 카테고리에서 지금 무엇이 뜨는가"를 4개 보드로 답합니다. 급상승 점수는 heat 색 pill로 통일 — 점수만 따라 읽어도 페이지가 스캔됩니다.

5. 검토·결정해 주세요

아래 5개가 합의되면 DESIGN.md에 기록하고 M4 구현 기준으로 확정합니다.

DQ1. 전체 톤틸 액센트 + 엠버 급상승 조합(유튜브 레드 회피)이 괜찮은지, 다른 색 방향을 원하는지.
DQ2. 보드 배치데스크톱 2×2 그리드(현재 시안) vs 탭으로 보드 전환(한 번에 하나, 행을 더 길게).
DQ3. 점수 표기영상은 "▲ 87" 점수, 유튜버는 "+13.6%" 성장률로 표기 구분 — 하나로 통일할지 유지할지.
DQ4. 보드당 행 수기본 노출 개수(시안은 4행) — 5행/10행 + "더 보기" 여부.
DQ5. 워드마크임시 워드마크 "▲ 트렌드 트레이서" — 서비스명·로고 방향 (추후 변경 가능, D1).
